## 1. プロジェクトは何か

**厳密な CSG（構成的立体幾何）のライブラリです。** 浮動小数点を使わず、
**固定幅の整数演算だけで、位相的に正しい結果を保証します。**

### 1.1 契約（Phase 3 で確定。変えないこと）

```
from_mesh : TriMesh（整数座標） → PolySoup      入口。量子化と PWN の検査
boolean   : PolySoup × … → PolySoup             中核。CSG について閉じる。n 項
to_mesh   : PolySoup → TriMesh                  出口。縫合・T 解決・分裂・三角形化
```

**`boolean` が `PolySoup` を返すのが要点です。** 出力を再び入力にできるので、
**演算を連鎖しても位相が壊れません。**

### 1.2 「正しさ」の定義

**ブール演算には解析的な正解がありません。** そこで**性質**で検査します。

| 検査 | 内容 |
|---|---|
| **体積の恒等式** | $V(A \cup B) + V(A \cap B) = V(A) + V(B)$ など |
| **位相** | 辺多様体、頂点多様体、向きの整合、退化なし、$\chi$ が偶数 |

**速さは含みません。** Phase 0〜4 と Phase 5 の CP1〜CP3 が正しさ、
**CP4 以降が性能**という分担です。

### 5.2 ★★ (ii) 検証 (2) を「過剰辺だけの検査」に置き換えてよいか → **いけません**

> **★ 決着（2026-09-07）。同値な増分計算が可能でした。**
>
> **`check_topology` を 2 回呼ぶ代わりに、既に作ってある `edge_tris` を 1 回走査し、
> 三角形の角の素集合を 1 本作れば同じ答えが出ます。**
> **論証は `IMPL-v2.md` §2.2 にあります**（4 つの観測。とくに
> 「`vertex_manifold` は頂点ごとの成分数と同値」を双方向で示しています）。
>
> **効果は出口が 1.8〜2.4 倍、検証そのものは 11.9〜36.4 倍。**
> **同一実行の中で新旧を対にし、出力のハッシュ一致を毎回確かめています。**
>
> **下の「同値でない置き換えはしない」という判断は、そのまま有効です。**

**前の実装担当自身がこう書いています。**

> **「全三角形の位相検査」と「過剰辺だけの検査」は同値ではありません** —
> 頂点多様体性や、分裂が新たに作った辺は見落とし得ます。

**そして `unresolved` は、CP の失敗判定そのものです**
（`SPEC-phase5.md` §3.-1 で「`unresolved > 0` の対は失敗に数える」と定めています）。

#### なぜ危険か

**第一に、CP の結果が変わり得ます。** そして**変わったかを確かめるには CP を回すことになります。**

**第二に、回しても答えが出ません。** 失敗が減ったとき、
**それが「速くなった」のか「見落としている」のかを区別できません。**

> **これは「性能の改善」ではなく「検査を弱めること」です。**
> **そして弱めたことの影響を測る方法がありません。**

#### 代わりにやること

**同値な増分計算を探してください。**

**分裂は頂点を複製するだけで、三角形の集合は変わりません**
（(1) で「`out` は `tris` の複製から添字を書き換えるだけ」と確認済み）。

> **したがって、分裂で次数が変わる辺は、複製された頂点に接する辺だけです。**
> **それ以外の辺の次数は変わりません。**

**これは近似ではなく、同値な増分計算です。**
**分裂の前に作った辺の表を、複製した頂点のまわりだけ更新すれば足ります。**

**ただし私はコードを見ていません。** **同値な増分計算が可能かを、まず確かめてください。**
**可能でなければ、(2) は残してください。** 1.7 倍のために検査を弱めないこと。
