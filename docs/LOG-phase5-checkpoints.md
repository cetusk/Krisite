| | セグメントトレース | レイキャストの加速 |

**Krisite は八分木を既に作っています。** source メッシュ側の索引を足すだけなら安い。

**数えるのは 1 行です。** 全数なら加速が有力、既に枝刈りしているなら余地は小さく、
**セグメントトレースに進むのが正しい。**

###### 出力の不変性 — 加速とトレースの決定的な差 ★

| | 出力の不変性 |
|---|---|
| **加速** | **同じ判定を速く行うだけ。ハッシュ一致で検証できる** |
| セグメントトレース | **判定の方式が変わる。** 摂動の解決が違えば、退化配置で答えが変わり得る |

判断できました。** 加速も同じ枠に入ります。

**セグメントトレースは、この枠から出る初めての変更になります。**
そのときは「出力が変わったら止まる」ではなく、

###### 浮動小数点の閾値は実測から決めてください

$$V(A \cup B) + V(A \cap B) = V(A) + V(B)$$
