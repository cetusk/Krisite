## シンボルの構成

**立方八面体**（cuboctahedron）を用いています。準多面体の定義（辺推移的かつ頂点推移的、
2種類の正多角形が交互に配置される）を満たす多面体は立方八面体と二十・十二面体の2つのみで、
前者を選んだのはロゴサイズでの可読性のためです。

- 頂点 12、辺 24、面 14（正三角形 8 + 正方形 6）
- 全頂点が同一球面上にあり、全辺長が等しい
- 座標は `(±1, ±1, 0)` の全順列

投影は正射影。Y軸 26°、X軸 −22°、Z軸 6° の回転で 7 面が可視になります。
陰影は面法線と光源方向 `(-0.35, 0.62, 0.70)` の内積から算出しており、
恣意的な塗り分けではありません。

### 表現している状態

1. **ダークグレーの面** — 既に貼り付けられたサーフェス
2. **ターコイズの正方形** — 直前に貼り付けられた面
3. **破線の開口部** — まだ面が置かれていない箇所。内部が見えている
4. **浮遊するターコイズの三角形** — いま貼り付けられようとしている一枚
5. **破線のガイド** — 面が着地する軌跡

点群からメッシュが構成されていく過程、および平面ベース表現で面を確定していく
過程を、静止画の一瞬として表しています。

## 再生成

`assets/` のSVGは投影計算から生成されています。生成スクリプトは `assets/gen_logo.py`。

```bash
python3 assets/gen_logo.py
```

角度・光源・配色・字幅を変える場合は、**スクリプト側のパラメータを変えて再生成**して
ください。SVG のポリゴン座標を手で編集すると、次の再生成で失われます。

主なパラメータ:

| 変数 | 意味 |
|---|---|
| `SLOPE` | K 断片の境界の傾き。現在 0.95（腕の「/」と合わせる） |
| `A` `B` `C` `TOP` | 断片の3段の境界 y |
| `LSB` `STEMW` | K の左サイドベアリングと縦画幅 |
| `LEG` `YBOT` | i の三角パッチの一辺と下端 |
| `FS` `LS` `W` | 文字サイズ・字間・字幅表 |

## ワードマーク

表記は **`Krisite`**（頭文字のみ大文字）。全大文字は使いません。

| 項目 | 値 |
|---|---|
| フォント | `'Helvetica Neue'` → `Helvetica` → `Arial` → `sans-serif` |
| サイズ | 62px / ウェイト 700 |
| 字間 | +3px |
| ベースライン | y = 100 |
| 文字色 | `krisite-logo.svg` = `#2E3741` / `krisite-logo-dark.svg` = `#E9EEF3` |

### ターコイズのアクセント2種

**1. K の左上先端** — 縦画の頭を斜めに切った断面。**3段のグラデーション**で層を表します。

| 段 | 色 |
|---|---|
| 上 | `#5EEAD4` |
| 中 | `#2DD4BF` |
| 下 | `#0D9488` |

3本の境界線はすべて **傾き 0.95（右上がり／水平から約 44°）** で、K の右上の腕「/」と平行です。
断片が腕の角度に沿って削り出されたように見えます。

断片の横幅は **K の縦画（|）の実寸** に合わせています。Helvetica Bold の
左サイドベアリング 0.076em・縦画幅 0.148em から算出。

| パラメータ | 値 |
|---|---|
| K 縦画 | x = 209.7 〜 218.5（幅 8.8） |
| 塗り範囲 | x = 207.7 〜 220.5（余剰はクリップで落ちる） |
| 境界の y（縦画左端 x=209.7 基準） | 66.0 / 75.0 / 84.0（上端 38.0） |

クリップは**二重**です。

1. `k-clip` — K の字形そのもの
2. `stem-clip` — 縦画の右端 `SR` で切る縦帯

1 だけだと、断片の下部が腕の付け根（縦画の右隣）に乗ります。2 を重ねることで
**塗りが縦画の外に出ないことが機械的に保証されます。**

**フォントを変える場合は `LSB` と `STEMW` を実測して更新してください。**
右にはみ出すなら `STEMW` を小さく、右端に地色が残るなら大きくします。

`clipPath` で K の字形そのものを切り抜いているため、**フォントが変わってもターコイズが
字形からはみ出しません。**

**2. i の点** — 丸ではなく、**正方形を半分にした直角二等辺三角形**。直角を左下に置き、
斜辺が左上から右下へ（`\`）走ります。K の「/」と逆向きにすることで単調さを避けています。
一辺 10px、下端 y=62.5（x-ハイト上端 y=67.8 との間隔 5.3px）。

`Krisite` には i が2つあるため、両方を三角にしています（片方だけだと誤植に見えます）。

実装上、i は **ドットレス i（U+0131 `ı`）** を使い、点は独立した三角形として重ねています。
グリフの x 座標は Helvetica Bold の字幅表（K=722, r=389, ı=278, s=556, t=333, e=556 /1000em）
から算出し、`<text>` の `x` 属性にリストで与えています。

```
x = 205, 252.8, 279.9, 300.1, 337.6, 357.8, 381.5
i の芯 = 288.5 / 346.2
```

**三角パッチの位置はこの計算に依存します。** フォントやサイズを変える場合は、
生成スクリプトの字幅表と `FS` / `LS` を更新して再計算してください。手で座標をずらさないこと。

## 使用上の注意

### ライト背景／ダーク背景

**`prefers-color-scheme` は使っていません。** このメディアクエリは OS のテーマ設定を
見ており、SVG が実際に置かれた背景色は見ません。ダークモードの OS で白背景のページに
貼ると、白い文字が白地に出て読めなくなります。

そのため2ファイルに分けています。

| ファイル | 用途 |
|---|---|
| `krisite-logo.svg` | 明るい背景 |
| `krisite-logo-dark.svg` | 暗い背景 |
| `krisite-mark.svg` | 文字なし。両方で使える |

GitHub の README で自動切替したい場合は `<picture>` を使ってください。

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="assets/krisite-logo-dark.svg">
  <img src="assets/krisite-logo.svg" alt="Krisite" width="440">
</picture>
```

これなら GitHub 側が実際の表示テーマに応じて出し分けます。

### viewBox とタグライン

`viewBox` の幅は **タグラインの実測幅から自動算出**しています（現在 711）。
固定値にすると、タグラインを書き換えたときに末尾が切れます。文言を変える場合は
`gen_logo.py` の `TAG` を書き換えて再生成してください。幅は自動で追従します。

タグラインの字幅は Helvetica Regular の字幅表 `TW` から計算しています。
**フォントを変える場合は `TW` も更新が必要です。**

### アウトライン化

**確定版として配布する際は、テキストをアウトライン化してください。**
Inkscape の場合は パス → オブジェクトをパスへ。理由は2つあります。

1. フォント非依存にするため
2. U+0131（ドットレス i）が未収録のフォントに置き換わると豆腐になるため

アウトライン化すれば、三角パッチの位置ずれも固定されます。
